# GEMINI STUDIO — GENERATION HANDOFF PROMPTS (Chapter 1 Premium v1.2)

> Clean copy/paste prompts for independent visual exploration. Gemini proposes **candidate directions/concepts**; it is NOT curriculum authority and NOT a release decision-maker.
> **Do not reveal prior candidate rankings, the expected winner, or any audit history.**

## Global rules for every prompt below

- Grade 4 elementary science. Premium modern, warm, academically credible, cinematic. Slight dimensionality. **Not** childish clip art, **not** generic corporate template.
- Palette: deep navy `#1F2A5A`, warm gold `#A67C16`, cream `#F5EEDC`, muted amber `#7A5620`. Grayscale-safe.
- Forbidden imagery (every direction): energy as a visible beam/substance/glow inside objects; particle streams; fake electron visuals; mechanism-level physics.
- Forbidden terminology (never render/emit): kinetic, potential, mechanical, radiant, compression wave, inertia.
- For vocabulary-card concepts, explore **composition/layout ideas only** — the instructional text (term + definition + Reader page) is rendered deterministically elsewhere, so focus on hero-art placement, framing, and how the card region divides.

## 1. Chapter opener alternatives

```
Explore 3 distinct visual directions for a Grade 4 science chapter opener
(16:9) titled "Energy Causes Change", theme DISCOVERY / EVIDENCE.
For each direction, return one concept image + a 1-line rationale.
The central idea: a change is the clue that energy was involved.
Directions should differ meaningfully (e.g., (a) a before/after room scene,
(b) a single hero object mid-change with a model glyph, (c) an
investigation/evidence motif with subtle magnifier framing).
A three-token model ENERGY -> CHANGE -> ? may appear as empty shapes (no
text). The third token must remain an unresolved "?" — never reveal an
answer.
Palette: deep navy, warm gold, cream, muted amber. Warm, cinematic,
slightly dimensional, grayscale-safe. No clip art, no corporate template.
No visible energy beams/glow. No rendered instructional words.
```

## 2. Vocabulary-card composition concepts

```
Explore composition/layout concepts for a collectible science vocabulary
card (landscape 14:9) used in Grade 4 science. THREE terms: ENERGY (the
ability to cause change), CHANGE (to become different), STORED ENERGY
(energy that has the ability to cause change at a later time).
Return 3 layout concepts showing how to divide the card: a TERM band
(top), a hero-art region (50-65% center), a definition band (bottom), and
a small footer. The words themselves will be rendered later, so show them
as gray placeholder bars/boxes, NOT actual text.
The hero-art region should feel collectible-but-credible (trading-card
FEEL, not imitation): restrained frame, one hero visual, chapter accent
bar. No rarity gems, no card-back, no game mechanics, no character art.
Palette: deep navy, warm gold, cream, muted amber. Grayscale-safe.
```

## 3. Five-form visual-system alternatives

```
Explore 2-3 distinct visual-system directions for a COHERENT five-card
family showing the five forms of energy (Grade 4): motion, sound, light,
heat, electrical energy.
Each direction must present all five as ONE intentional family (same
style, palette, card grid). Return one concept image per direction showing
the full 16:9 five-card row.
Concrete examples: motion = spinning carousel/rolling ball; sound =
ringing bell (subtle vibration, no literal sound rays); light = lamp
illuminating a room; heat = warm mug (steam) with warming context, avoid
flames; electrical energy = a powered device turning on.
Labels are added later — show a clean empty band at the top of each card.
Forbidden: abstract energy beams, glowing energy matter, particle streams,
fake electron visuals, unrelated decorative symbols, cartoon clip art.
Palette: deep navy, warm gold, cream, muted amber. Grayscale-safe.
```

## 4. ENERGY → CHANGE → EVIDENCE alternatives

```
Explore 3 visual directions for a Grade 4 instructional model:
ENERGY -> CHANGE -> EVIDENCE (a change you observe is evidence energy was
involved).
Each direction: three rounded navy nodes joined left-to-right by warm-gold
arrows. Vary the presentation meaningfully: (a) clean diagram on white,
(b) diagram over a soft seashore photographic backdrop, (c) a "puzzle
reveal" where the third node is visually hidden/veiled until revealed.
The three words are added later; show the nodes as empty rounded shapes
with an empty interior band. The third node must read as UNRESOLVED (not
an answer).
Minimal, one concept, large empty label spaces, high contrast. No
mechanism arrows (wave/particle physics). No energy visible in the wave.
Palette: deep navy, warm gold, cream, muted amber. Grayscale-safe.
```

## 5. Dark / bright treatment concepts

```
Explore 3 visual directions for a Grade 4 science slide showing a
dark-room -> bright-room change (the room "became different").
Each direction: a before/after pair with IDENTICAL framing — the change
(dark -> bright) is the only variable. Return one concept image per
direction.
Warm, realistic/photorealistic, clean, no busy background. No visible
energy beam; no "energy as substance". Palette: deep navy, warm gold,
cream, muted amber. Grayscale-safe. No text (labels overlaid later).
```

## 6. Stored-energy concept directions

```
Explore 3 visual directions for Grade 4 science on STORED ENERGY (a still
object can store energy to cause change later).
Cover three objects across the directions: (a) a battery in an OFF
flashlight, (b) a stretched rubber band held still, (c) an apple held
above the ground (position).
Each object must be STILL (not moving, not releasing). Show position /
held state clearly; no visible energy inside the object; no "energy glow".
Return one concept image per direction.
Realistic/photorealistic or clean instructional illustration. Warm,
premium, high contrast. Palette: deep navy, warm gold, cream, muted amber.
Grayscale-safe. No text (labels overlaid later).
```
